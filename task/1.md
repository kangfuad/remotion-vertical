# 8. TECHNICAL ACCURACY

The video must explain SQL and NoSQL accurately.

Important educational distinctions:

1. SQL databases are generally relational databases.
2. SQL is a query language, not a database product.
3. NoSQL is a broad category, not one specific database architecture.
4. Document databases are only one type of NoSQL.
5. Not every NoSQL database has the same consistency model.
6. SQL databases can also scale horizontally.
7. NoSQL databases can also support ACID transactions.
8. Database selection depends on data model, consistency requirements, access patterns, and operational needs.

Do not claim:

- SQL is always slower.
- NoSQL is always faster.
- SQL cannot scale horizontally.
- NoSQL cannot support transactions.
- NoSQL has no schema whatsoever.

Keep the explanation beginner-friendly without introducing inaccurate simplifications.
